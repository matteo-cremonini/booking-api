# booking-api

Multi-tenant booking API built with Django REST Framework.

Providers manage services and availability. Clients book appointments.

## Stack

- Django 6 + Django REST Framework
- SimpleJWT authentication
- Role-based permissions (provider / client)
- django-filter
- PostgreSQL (production) / SQLite (development)
- Docker (local) / Railway (production)
